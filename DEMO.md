## Before the judge walks up (30 s prep)

1. Dev server running: `cd app && npm run dev` (optional: `cd server && npm start` for shared board).
2. Hard-refresh once (**Ctrl+Shift+R**).
3. Leave the app on the **start screen** — attract mode hops behind the pathway card.
