# Sponsor art stubs (SpaceXAI / Grok Imagine)

Drop Grok Imagine exports here as:
  - title.png          (hero / splash)
  - region_cx.png      (central complex card art)
  - region_mb.png
  - region_al.png
  - portrait_human.png
  - portrait_fly.png

The in-game 3D human/fly are voxel meshes built in Three.js
(app/src/game/WorldView.ts) — Grok outputs 2D, not voxel models.

Vultr: only needed if you deploy server/ + app/dist; local demo
works offline without it.
